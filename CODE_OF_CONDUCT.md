# Code of Conduct

This project is meant to be a welcoming place to build something useful together.

**The short version:** be respectful, be constructive, assume good faith. Critique ideas,
not people. No harassment, discrimination, or personal attacks. No spam or bad-faith
participation.

This applies to issues, pull requests, discussions, and any other project space.

**Enforcement:** maintainers may edit, hide, or remove contributions that violate these
norms, and may block repeat or serious offenders. If you experience or witness unacceptable
behaviour, open a confidential report by contacting the maintainers at the address listed on
the project's GitHub organization profile.

We aim to handle reports promptly, fairly, and with discretion.
