# Task Planner App Idea

Simple AI-assisted task planner that learns from your preferences:

- Parse natural language task descriptions
- Auto-estimate effort (1-4 hours)
- Suggest related previous tasks for context
- Group by project using vault scopes
- Export weekly summary as markdown

Could integrate with EleSync for persistent memory across sessions.

Key insight: most task planners fail because they don't remember context from previous projects. Having a searchable vault of past decisions would be powerful.
